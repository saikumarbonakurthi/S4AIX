# SAP August Developer Challenge — Week 4

A Next.js business card for the SAP Joule Studio Week 4 Vercel challenge.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Deploy

Import this repository into Vercel and set:

```text
CAP_SERVICE_URL=https://community-challenge.cfapps.us10.hana.ondemand.com
```

After deployment, open the live URL and select **Submit to SAP Community**.
